## What is Apiary?

Apiary is a **TypeScript-first scheduling library** you can embed in any modern web application or backend service. It is built entirely on Web Standard APIs — `Date`, `Intl`, `Request` / `Response`, `fetch` — with no framework coupling and no required compilers.

## How it works

Availability flows through two pure steps:

1. **Windows** — spans of time that *could* be bookable (`AvailableWindow[]`).
   - *Dynamic mode:* expanded from weekly recurring rules via `expandWeeklyRules`.
   - *Explicit mode:* stored, admin-published shift records.
2. **Slots** — `generateTimeSlots` carves a window into candidate slots, then marks each one `available` or not by applying buffers, minimum notice, the booking horizon, and collisions with existing bookings and holds.

The [PostgreSQL adapter](guides/postgres/) turns this into a full booking backend with atomic holds and confirmation, while the pure core stays framework- and storage-agnostic.
